# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Instead, report it privately by email or by opening a draft security advisory on GitHub. We will respond as soon as possible and work with you to resolve the issue responsibly.

## Security Best Practices for Users

- Keep your `DISCORD_TOKEN`, `DISCORD_CLIENT_SECRET`, and `SESSION_SECRET` confidential.
- Never commit `.env` files or database files to version control.
- Review dependencies before deploying to production.
