# Changelog

## [0.1.0] - 2026-09-12

### Added

- Initial public Discord bot template.
- Bun + discord.js bot core with dynamic command and context menu loading.
- Hono web server with `/health`, Discord OAuth shell, and Activity shell.
- Vite + React admin UI and Activity shell.
- Turso / SQLite Drizzle ORM layer with control and per-guild databases.
- Database migration and provisioning scripts.
- Dockerfile, docker-compose, and GitHub Actions CI.
- Bilingual README (English / Japanese).
- Architecture diagram (`docs/architecture.drawio`) and architecture rationale docs.
- CONTRIBUTING, SECURITY, and CODE_OF_CONDUCT.
